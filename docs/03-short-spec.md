# 03. Супориши кӯтоҳи техникӣ
## Лоиҳа: «Коркарди веб-барномаи идоракунии фитнес-клуб»

## 1. Маълумоти умумӣ

**Номи лоиҳа:** Веб-барномаи идоракунии фитнес-клуб  
**Номи кӯтоҳ:** Fitness Club Management System  
**Навъи система:** Веб-барномаи иттилоотӣ  
**Соҳаи истифода:** Идоракунӣ ва автоматикунонии фаъолияти фитнес-клуб  
**Забони интерфейс:** Тоҷикӣ  
**Пойгоҳи додаҳо:** MySQL 8.0+  
**Қисми серверӣ:** Go (Golang)  
**Қисми муштарӣ:** HTML5, CSS3, JavaScript  

## 2. Асос барои коркард

Асоси коркард натиҷаҳои марҳилаҳои қаблӣ мебошанд:

- таҳлили соҳаи мавзӯӣ ва равандҳои фаъолияти фитнес-клуб;
- муайян кардани иштирокчиён ва нақшҳои корбарон;
- омӯзиш ва муқоисаи системаҳои мавҷудаи идоракунии фитнес-клубҳо;
- муайян кардани мушкилоти баҳисобгирии дастӣ ва зарурати автоматикунонӣ.

Система ҳамчун лоиҳаи таълимӣ таҳия шуда, бояд равандҳои асосии кори фитнес-клубро дар як веб-барнома муттаҳид намояд.

## 3. Мақсад ва вазифаи система

### 3.1. Мақсад

Мақсади лоиҳа коркарди веб-барномаи ягона барои идоракунии мизоҷон, мураббиён, хизматрасониҳо, обунаҳо, ҷадвали машқҳо, сабти мизоҷон, ҳозиршавӣ ва пардохтҳо мебошад.

### 3.2. Вазифаҳои асосӣ

1. Таъмини бақайдгирӣ ва воридшавии бехатари корбарон.
2. Идоракунии нақшҳо ва ҳуқуқи дастрасӣ.
3. Нигоҳдорӣ ва таҳрири маълумоти мизоҷон ва мураббиён.
4. Идоракунии хизматрасониҳо ва намудҳои обуна.
5. Ба расмият даровардан ва тамдиди обунаҳо.
6. Тартиб додани ҷадвали машқҳои гурӯҳӣ ва инфиродӣ.
7. Сабти мизоҷон ба машғулиятҳо ва назорати ҷойҳои холӣ.
8. Баҳисобгирии ҳозиршавӣ.
9. Бақайдгирии пардохтҳо.
10. Таҳияи маълумоти ҷамъбастӣ барои маъмурият.

## 4. Истифодабарандагони система

Система чор нақши асосии корбарро дастгирӣ мекунад:

| Нақш | Ҳуқуқ ва вазифаҳои асосӣ |
|---|---|
| Маъмур | Идоракунии корбарон, нақшҳо, мизоҷон, мураббиён, хизматрасониҳо, обунаҳо, ҷадвал ва ҳисоботҳо. |
| Менеҷер | Бақайдгирии мизоҷон, идоракунии обунаҳо, сабти пардохтҳо ва амалиётҳои иҷозатдодашудаи мизоҷон. |
| Мураббӣ | Дидани ҷадвали шахсӣ, рӯйхати иштирокчиён ва қайд кардани ҳозиршавӣ. |
| Мизоҷ | Дидани хизматрасониҳо, ҷадвал, обунаи шахсӣ, сабт ба машқҳо ва таърихи ҳозиршавӣ. |

Ҳар як корбар танҳо ба вазифаҳо ва маълумоти мувофиқи нақши худ дастрасӣ мегирад. Санҷиши ҳуқуқ бояд дар қисми серверӣ иҷро шавад.

## 5. Талаботи функсионалӣ

Система бояд талаботи зеринро иҷро намояд:

| Рамз | Талабот |
|---|---|
| FR-01 | Бақайдгирӣ, воридшавӣ ва баромад аз ҳисобро таъмин намояд. |
| FR-02 | Нақшҳо ва ҳуқуқи дастрасии корбаронро идора намояд. |
| FR-03 | Маълумоти мизоҷонро илова, намоиш ва таҳрир намояд. |
| FR-04 | Маълумоти мураббиён ва ихтисоси онҳоро нигоҳ дорад. |
| FR-05 | Хизматрасониҳо ва намудҳои обунаро идора намояд. |
| FR-06 | Обунаи мизоҷро ба расмият дарорад, тамдид ва назорат кунад. |
| FR-07 | Ҷадвали машқҳоро созад, намоиш диҳад ва таҳрир намояд. |
| FR-08 | Мураббиро ба машғулият таъин карда, ба ҳам омадани вақти машқҳоро санҷад. |
| FR-09 | Мизоҷонро ба машғулият сабт карда, ҷойҳои холиро назорат намояд. |
| FR-10 | Аз сабти такрории фаъоли як мизоҷ ба як машғулият пешгирӣ кунад. |
| FR-11 | Ҳозиршавӣ ё набудани мизоҷро ба қайд гирад. |
| FR-12 | Пардохтҳоро сабт ва таърихи онҳоро намоиш диҳад. |
| FR-13 | Ба мизоҷ дидани профил, обуна ва таърихи шахсии худро иҷозат диҳад. |
| FR-14 | Барои маъмурият маълумоти ҷамъбастӣ пешниҳод намояд. |

## 6. Талаботи ғайрифунксионалӣ

1. **Амният:** рамзҳо бояд бо алгоритми ҳешкунии мувофиқ нигоҳ дошта шаванд; рамзҳои аслӣ дар пойгоҳи додаҳо нигоҳ дошта нашаванд.
2. **Идоракунии дастрасӣ:** сервер бояд ҳуқуқи корбарро пеш аз иҷрои ҳар як амалиёти муҳофизатшаванда санҷад.
3. **Якпорчагии маълумот:** калидҳои ибтидоӣ, калидҳои хориҷӣ, маҳдудиятҳо ва транзаксияҳои MySQL истифода шаванд.
4. **Қулайии истифода:** интерфейс бояд фаҳмо, мутобиқшаванда ва бо забони тоҷикӣ бошад.
5. **Мутобиқат:** барнома бояд дар браузерҳои муосир ва андозаҳои гуногуни экран дуруст намоиш дода шавад.
6. **Эътимоднокӣ:** хатогиҳои воридкунии маълумот бояд бо паёмҳои фаҳмо нишон дода шаванд.
7. **Нигоҳдорӣ ва рушд:** рамзи Go бояд ба модулҳои дорои вазифаҳои ҷудогона тақсим карда шавад.
8. **Махфият:** маълумоти шахсии мизоҷон набояд ба корбарони бе иҷозат дастрас бошад.

## 7. Талабот ба маълумот ва пойгоҳи додаҳо

Барои версияи аввал ҷадвалҳои асосии зерин пешбинӣ мешаванд:

| Ҷадвал | Вазифа |
|---|---|
| `users` | Ҳисобҳои корбарӣ ва нақшҳо |
| `clients` | Маълумоти мизоҷон |
| `trainers` | Маълумоти мураббиён |
| `services` | Хизматрасониҳои фитнес-клуб |
| `membership_types` | Намуд ва шартҳои обуна |
| `memberships` | Обунаҳои мизоҷон |
| `training_sessions` | Машқҳо ва ҷадвали онҳо |
| `bookings` | Сабти мизоҷон ба машғулиятҳо |
| `attendance` | Маълумоти ҳозиршавӣ |
| `payments` | Маълумоти пардохтҳо |

Пойгоҳи додаҳо бояд робитаҳои байни ҷадвалҳоро бо калидҳои хориҷӣ таъмин намояд. Таркиби ниҳоии майдонҳо ва маҳдудиятҳо дар марҳилаи тарҳрезии пойгоҳи додаҳо муайян карда мешавад.

## 8. Маҳдудиятҳо ва қоидаҳои асосии корӣ

- Сабт ба машғулият танҳо ҳангоми мавҷуд будани ҷойи холӣ иҷозат дода мешавад.
- Шумораи сабтҳои фаъоли машғулияти гурӯҳӣ набояд аз ғунҷоиши он зиёд бошад.
- Як мизоҷ набояд ба як машғулият ду сабти фаъоли якхела дошта бошад.
- Мураббӣ набояд ба машқҳои ҳамзамон таъин карда шавад.
- Ҳангоми зарурат сабт ба машқ бояд фаъол будани обуна ва шартҳои онро санҷад.
- Пардохт бояд маблағи мусбат дошта бошад.
- Амалиётҳои вобаста, ки якчанд ҷадвалро тағйир медиҳанд, бояд бо транзаксия иҷро шаванд.
- Танҳо корбарони ваколатдор метавонанд маълумот ва ҳолати амалиётҳоро тағйир диҳанд.

Қоидаҳои дақиқи бекор кардани сабт, баргардонидани маблағ ва ях кардани обуна дар марҳилаи татбиқи мантиқи корӣ муайян карда мешаванд.

## 9. Технология ва меъмории система

Барои коркарди система технологияҳои зерин интихоб шудаанд:

| Қисм | Технология |
|---|---|
| Backend | Go (Golang) |
| Frontend | HTML5, CSS3, JavaScript |
| Пойгоҳи додаҳо | MySQL 8.0+ |
| API | REST API |
| Формати мубодилаи маълумот | JSON |
| Муҳити коркард | Visual Studio Code |
| Муҳити маҳаллӣ | Windows ва XAMPP |
| Назорати версияҳо | Git ва GitHub |

Меъмории система аз се қисми асосӣ иборат мешавад:

1. **Қисми муштарӣ:** интерфейси веб, ки дар браузер иҷро мешавад.
2. **Қисми серверӣ:** API ва мантиқи корӣ, ки бо Go амалӣ карда мешавад.
3. **Қабати маълумот:** пойгоҳи додаҳои MySQL барои нигоҳдорӣ ва коркарди маълумот.

Схемаи умумии ҳамкорӣ:

```text
Корбар
   |
   v
Браузер (HTML, CSS, JavaScript)
   |
   | HTTP / JSON
   v
Сервер (Go / REST API)
   |
   v
Мантиқи корӣ ва санҷиши ҳуқуқ
   |
   v
MySQL
```

## 10. Натиҷаҳои интизоршаванда

Дар натиҷаи иҷрои лоиҳа бояд веб-барномаи дорои имкониятҳои зерин омода шавад:

- воридшавӣ ва идоракунии корбарон аз рӯйи нақш;
- идоракунии мизоҷон ва мураббиён;
- идоракунии хизматрасониҳо ва обунаҳо;
- тартиб додани ҷадвали машқҳо;
- сабти мизоҷон ба машғулиятҳо;
- назорати ҷойҳои холӣ;
- баҳисобгирии ҳозиршавӣ;
- бақайдгирии пардохтҳо;
- намоиши маълумоти ҷамъбастӣ барои маъмурият.

## 11. Меъёрҳои қабули система

Система метавонад қабулшуда ҳисобида шавад, агар:

1. Ҳамаи нақшҳои пешбинишуда ба вазифаҳои иҷозатдодашуда дастрасӣ дошта бошанд.
2. Амалиётҳои асосии илова, дидан ва таҳрири маълумот дуруст иҷро шаванд.
3. Обунаҳо ва пардохтҳо дуруст ба қайд гирифта шаванд.
4. Ҷадвали машқҳо ва таъини мураббиён дуруст кор кунанд.
5. Система аз сабти такрорӣ ва зиёд шудани шумораи иштирокчиён пешгирӣ намояд.
6. Ҳозиршавӣ дуруст сабт шавад.
7. Робитаҳои пойгоҳи додаҳо якпорчагии маълумотро нигоҳ доранд.
8. Санҷишҳои асосӣ бе хатои ҷиддӣ гузаранд.
9. Дастури насб ва оғози барнома омода бошад.

## 12. Марҳилаҳои минбаъдаи коркард

1. Таҳияи диаграммаҳои UML ва моделсозии рафтори система.
2. Тарҳрезии сохтори пойгоҳи додаҳо ва ER-диаграмма.
3. Таҳияи модели мантиқӣ ва ҷадвалҳои SQL.
4. Тарҳрезии интерфейси корбар.
5. Коркарди қисми серверӣ бо Go.
6. Коркарди қисми муштарӣ бо HTML, CSS ва JavaScript.
7. Пайваст кардани барнома ба MySQL.
8. Санҷиш, ислоҳи хатогиҳо ва омода намудани ҳуҷҷатҳои ниҳоӣ.

## 13. Хулоса

Дар супориши кӯтоҳи техникӣ мақсад, вазифа, истифодабарандагон, талаботи функсионалӣ ва ғайрифунксионалӣ, маҳдудиятҳо, технологияҳо ва натиҷаҳои интизоршавандаи веб-барномаи идоракунии фитнес-клуб муайян карда шуданд.

Ин ҳуҷҷат асоси марҳилаҳои минбаъдаи тарҳрезӣ ва коркарди система мебошад. Ҳангоми таҳияи диаграммаҳо, пойгоҳи додаҳо ва модулҳои барнома талаботи мазкур ҳамчун замина истифода мешаванд.
