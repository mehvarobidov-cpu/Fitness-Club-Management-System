# Тарҳрезии пойгоҳи додаҳо — Fitness Club Management

## 1. Маълумоти умумӣ

Пойгоҳи додаҳои системаи идоракунии фитнес-клуб бо истифода аз **MySQL 8.0+** тарҳрезӣ мешавад. Номи пойгоҳи додаҳо `fitness_club_db` буда, рамзгузории `utf8mb4` истифода мешавад, то матни тоҷикӣ ва дигар аломатҳо дуруст нигоҳ дошта шаванд.

## 2. Ҷадвалҳо ва вазифаи онҳо

| № | Ҷадвал | Вазифа |
|---|---|---|
| 1 | `users` | Маълумоти воридшавӣ, нақш ва ҳолати истифодабарандагон |
| 2 | `clients` | Маълумоти иловагии муштариён |
| 3 | `trainers` | Маълумоти касбӣ ва тахассуси мураббиён |
| 4 | `membership_plans` | Намудҳо ва нархи узвият |
| 5 | `memberships` | Узвияти муштарӣ, сана ва ҳолати он |
| 6 | `services` | Хизматрасониҳо ва машғулиятҳои клуб |
| 7 | `training_sessions` | Ҷадвали машғулиятҳо, мураббӣ, вақт ва ғунҷоиш |
| 8 | `bookings` | Бронкунии машғулият аз ҷониби муштарӣ |
| 9 | `attendance` | Сабти ҳозиршавӣ ба машғулият |
| 10 | `payments` | Пардохтҳои муштариён |

## 3. Робитаҳои асосӣ

- `users` бо `clients` робитаи як-ба-як дорад: як ҳисоби муштарӣ танҳо як профили муштарӣ дорад.
- `users` бо `trainers` робитаи як-ба-як дорад.
- Як муштарӣ метавонад якчанд узвият дошта бошад; ҳар узвият ба як нақшаи узвият вобаста аст.
- Як мураббӣ метавонад якчанд машғулият гузаронад.
- Ҳар машғулият ба як хизматрасонӣ ва як мураббӣ вобаста аст.
- Муштарӣ метавонад машғулиятҳои гуногунро брон кунад. Барои як муштарӣ ва як машғулият танҳо як сабти брон нигоҳ дошта мешавад.
- Ҳар брон метавонад ҳадди аксар як сабти ҳозиршавӣ дошта бошад.
- Пардохт ба муштарӣ ҳатман вобаста аст ва метавонад ба узвияти мушаххас пайваст карда шавад.

## 4. Қоидаҳои якпорчагии додаҳо

1. Калидҳои асосӣ `BIGINT UNSIGNED AUTO_INCREMENT` мебошанд.
2. Калидҳои берунӣ робитаҳои байни ҷадвалҳоро нигоҳ медоранд.
3. Барои санаи узвият шарти `end_date >= start_date` истифода мешавад.
4. Ғунҷоиши машғулият бояд аз сифр зиёд бошад.
5. Нархи хизматрасонӣ ва нақшаи узвият манфӣ буда наметавонад.
6. Маблағи пардохт бояд аз сифр зиёд бошад.
7. Барои пешгирии бронкунии такрорӣ маҳдудияти `UNIQUE(client_id, session_id)` истифода мешавад.
8. Барои нигоҳ доштани таърихи молиявӣ ва бронҳо, сабтҳои вобаста ба онҳо бо `ON DELETE RESTRICT` ҳифз мешаванд.

## 5. Қоидаҳое, ки бояд дар Backend иҷро шаванд

Баъзе қоидаҳо танҳо бо `FOREIGN KEY` ё `CHECK` таъмин намешаванд. Онҳо бояд дар Go ва дар транзаксияи пойгоҳи додаҳо санҷида шаванд:

- Ҳангоми бронкунӣ ҳолати машғулият, узвияти фаъол, мавҷудияти ҷой ва набудани бронкунии такрорӣ санҷида шавад.
- Ҳисоб ва кам кардани ҷойҳои дастрас бояд дар транзаксия ва бо муҳофизат аз дархостҳои ҳамзамон иҷро шавад.
- Пеш аз сабти ҳозиршавӣ бояд брон ба ҳамон муштарӣ ва машғулият тааллуқ дошта бошад.
- Барои мураббӣ набояд ду машғулияти ҳамзамони бо вақт ҳампӯш вуҷуд дошта бошад.
- Барои муштарӣ қоидаи узвияти ҳамзамон бояд аз рӯйи сиёсати клуб муайян ва дар Backend санҷида шавад.
- Танҳо корбарони дорои нақши мувофиқ метавонанд амалиёти маъмурӣ, идоракунии пардохт ё сабти ҳозиршавиро иҷро кунанд.
- Парол танҳо дар шакли hash нигоҳ дошта шавад; пароли аслӣ дар пойгоҳи додаҳо сабт нашавад.

## 6. Тавзеҳот дар бораи брон

Дар ин тарҳ барои ҳар ҷуфти `client_id` ва `session_id` як сабт нигоҳ дошта мешавад. Агар муштарӣ бронро бекор кунад ва баъд дубора брон кардан хоҳад, Backend бояд сабти мавҷударо бо санҷиши транзаксионӣ аз ҳолати `cancelled` ба `booked` баргардонад, на ин ки сабти дуюм эҷод кунад.

## 7. Файлҳои марҳила

- `database/01-schema.sql` — скрипти сохтани пойгоҳи додаҳо ва ҷадвалҳо.
- `docs/06-database/01-database-design.md` — ҳуҷҷати тарҳрезӣ ва шарҳи робитаҳо.

## 8. Тартиби иҷро

1. MySQL 8.0+ -ро оғоз кунед.
2. Файли `database/01-schema.sql`-ро дар MySQL Workbench ё phpMyAdmin иҷро кунед.
3. Санҷед, ки пойгоҳи додаи `fitness_club_db` ва 10 ҷадвал сохта шудаанд.
4. Пеш аз пайваст кардани Backend, номи пойгоҳи дода ва маълумоти пайвастшавиро дар файли танзимоти Go мувофиқ кунед.

## 9. Хулоса

Сохтори пешниҳодшуда маълумоти асосии муштариён, кормандон, узвият, хизматрасонӣ, ҷадвал, брон, ҳозиршавӣ ва пардохтҳоро фаро мегирад. Қоидаҳои муҳимми амалиётӣ дар Backend низ бояд санҷида шаванд, то якпорчагӣ ва дурустии додаҳо нигоҳ дошта шавад.
