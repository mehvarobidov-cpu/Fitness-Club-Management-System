# 01. Таҳлили соҳаи мавзӯӣ
## Лоиҳа: «Коркарди веб-барномаи идоракунии фитнес-клуб»

## 1. Тавсифи умумии соҳаи мавзӯӣ

Фитнес-клуб ташкилотест, ки ба мизоҷон хизматрасониҳои варзишию солимгардонӣ пешниҳод мекунад. Ба ин хизматрасониҳо толори машқ, машғулиятҳои гурӯҳӣ, тамринҳои инфиродӣ ва барномаҳои иловагӣ дохил мешаванд. Барои фаъолияти самараноки клуб ҳамоҳангсозии кори маъмурият, менеҷерон, мураббиён ва мизоҷон зарур аст.

Дар фаъолияти ҳаррӯзаи фитнес-клуб маълумот дар бораи мизоҷон, кормандон, хизматрасониҳо, обунаҳо, пардохтҳо, ҷадвали машқҳо, сабти ном ба машғулиятҳо ва ҳозиршавӣ коркард мешавад. Ҳангоми пешбурди дастии ҳисобот ё нигоҳ доштани маълумот дар файлҳои ҷудогона ҷустуҷӯи маълумот, назорати муҳлати обуна, ҳисоб кардани ҷойҳои холӣ ва омода намудани ҳисобот мушкил мегардад.

Лоиҳаи мазкур веб-барномаест, ки барои идоракунии мутамаркази равандҳои асосии фитнес-клуб пешбинӣ шудааст.

## 2. Мақсад ва вазифаи система

### 2.1. Мақсади коркард

Коркарди веб-барнома барои автоматикунонии равандҳои ташкилӣ ва ҳисоббаробаркунии фитнес-клуб, баланд бардоштани дақиқии нигоҳдории маълумот ва осон намудани ҳамкории маъмурият, мураббиён ва мизоҷон.

### 2.2. Вазифаи система

Система барои иҷрои вазифаҳои зерин пешбинӣ мешавад:
- нигоҳдорӣ ва коркарди маълумот дар бораи мизоҷон ва кормандон;
- идоракунии хизматрасониҳо ва намудҳои обуна;
- ба расмият даровардан, тамдид ва назорати обунаҳо;
- тартиб додани ҷадвали машқҳо;
- сабти мизоҷон ба машғулиятҳои гурӯҳӣ ва инфиродӣ;
- баҳисобгирии ҳозиршавӣ;
- бақайдгирии пардохтҳо;
- таҳияи маълумоти ҷамъбастӣ оид ба фаъолияти клуб.

## 3. Ҳудуди соҳаи мавзӯӣ

Дар доираи лоиҳа равандҳои зерин баррасӣ мешаванд:

1. Бақайдгирии корбарон ва идоракунии ҳисобҳои корбарӣ.
2. Пешбурди махзани маълумоти мизоҷон ва мураббиён.
3. Идоракунии хизматрасониҳо ва самтҳои фитнес-клуб.
4. Сохтани намудҳои обуна ва ба расмият даровардани обунаи мизоҷон.
5. Банақшагирии машқҳои гурӯҳӣ ва инфиродӣ.
6. Сабт ва бекор кардани сабт ба машғулиятҳо.
7. Баҳисобгирии ҳозиршавии воқеӣ.
8. Бақайдгирии пардохтҳо.
9. Таҳияи ҳисобот барои маъмурият.

Пайвастшавӣ ба низомҳои бонкии пардохт, барномаи мобилӣ, назорати даромад тавассути турникет, баҳисобгирии муҳосибӣ ва ҳамгироӣ бо низомҳои берунии CRM ба ҳаҷми ҳатмии версияи аввал дохил намешаванд. Ин имкониятҳо метавонанд дар марҳилаҳои минбаъда илова карда шаванд.

## 4. Иштирокчиёни соҳаи мавзӯӣ

| Иштирокчӣ | Тавсиф | Манфиатҳои асосӣ |
|---|---|---|
| Соҳиби фитнес-клуб | Масъули фаъолияти умумии клуб | Назорати кор, сарборӣ ва нишондиҳандаҳо |
| Маъмур | Идоракунандаи система ва маълумоти асосӣ | Дурустии маълумот ва идоракунии дастрасӣ |
| Менеҷер | Бо мизоҷон, обунаҳо ва пардохтҳо кор мекунад | Хизматрасонии босифат ва баҳисобгирии дақиқ |
| Мураббӣ | Машқҳои гурӯҳӣ ва инфиродиро мегузаронад | Ҷадвали дуруст ва рӯйхати иштирокчиён |
| Мизоҷ | Аз хизматрасониҳои фитнес-клуб истифода мебарад | Дидани хизматрасониҳо, обуна ва сабт ба машқҳо |

### 4.1. Нақшҳои корбарон дар веб-барнома

**Маъмур (Administrator):**
- идоракунии ҳисобҳои корбарӣ ва нақшҳо;
- идоракунии маълумоти мизоҷон, мураббиён, хизматрасониҳо ва обунаҳо;
- сохтан ва тағйир додани ҷадвали машқҳо;
- дидани ҳисобот ва маълумоти умумии клуб.

**Менеҷер (Manager):**
- бақайдгирӣ ва таҳрири маълумоти мизоҷон;
- ба расмият даровардан ва тамдид кардани обунаҳо;
- бақайдгирии пардохтҳо;
- кӯмак ба мизоҷон ҳангоми сабт ба машғулиятҳо;
- баҳисобгирии ҳозиршавӣ дар доираи ҳуқуқҳои додашуда.

**Мураббӣ (Trainer):**
- дидани ҷадвали шахсии корӣ;
- дидани машқҳои таъиншуда ва рӯйхати иштирокчиён;
- қайд кардани ҳозиршавии мизоҷон.

**Мизоҷ (Client):**
- дидан ва таҳрир кардани маълумоти иҷозатдодашудаи профили худ;
- дидани хизматрасониҳо ва ҷадвали машқҳо;
- дидани маълумоти обунаи шахсӣ;
- сабт ва бекор кардани сабт ба машқҳо тибқи қоидаҳои клуб;
- дидани таърихи ҳозиршавӣ.

Ҳуқуқи дастрасӣ бояд дар тарафи сервер санҷида шавад. Танҳо пинҳон кардани унсурҳои интерфейс барои ҳифзи маълумот кофӣ нест.

## 5. Равандҳои асосии корӣ

### 5.1. Бақайдгирии мизоҷ

1. Мизоҷ ба фитнес-клуб муроҷиат мекунад ё тавассути веб-барнома сабти ном мешавад.
2. Маълумоти зарурии шахсӣ ба система ворид карда мешавад.
3. Система пур будани майдонҳои ҳатмӣ ва такрор нашудани маълумоти ҳисобро месанҷад.
4. Профили мизоҷ сохта мешавад.
5. Мизоҷ имкони ворид шудан ба кабинети шахсиро мегирад.

**Натиҷа:** дар система ҳисоби корбарӣ ва профили мизоҷ сохта мешавад.

### 5.2. Ба расмият даровардани обуна

1. Менеҷер мизоҷро интихоб мекунад.
2. Намудҳои дастраси обунаро мебинад.
3. Навъи мувофиқи обунаро интихоб мекунад.
4. Система нарх, муҳлати амал ва шумораи иҷозатдодашудаи ташрифҳоро тибқи тарофа муайян мекунад.
5. Менеҷер пардохтро ба қайд мегирад.
6. Система обуна ва ҳолати онро нигоҳ медорад.

**Натиҷа:** барои мизоҷ обуна бо шартҳои муайян ба расмият дароварда мешавад.

### 5.3. Тартиб додани ҷадвали машқҳо

1. Маъмур намуди машғулиятро интихоб мекунад.
2. Ном, сана, вақт ва давомнокии машқро муайян мекунад.
3. Мураббиро таъин менамояд.
4. Шумораи ҳадди аксари иштирокчиёнро нишон медиҳад.
5. Система дурустии маълумот ва мувофиқ омадани вақти машқҳоро барои мураббӣ месанҷад.
6. Машғулият нигоҳ дошта шуда, барои дидан дастрас мегардад.

**Натиҷа:** дар ҷадвал машғулияти нав пайдо мешавад.

### 5.4. Сабти мизоҷ ба машқ

1. Мизоҷ ҷадвали машқҳоро мекушояд.
2. Машғулияти дастрасро интихоб мекунад.
3. Система мавҷуд будани ҷойҳои холиро месанҷад.
4. Агар қоидаҳои клуб талаб кунанд, фаъол будани обуна ва мувофиқати шартҳои онро месанҷад.
5. Система мавҷуд набудани сабти дигари фаъоли ҳамин мизоҷро ба ҳамон машғулият месанҷад.
6. Сабти мизоҷ ба машқ сохта мешавад.

**Натиҷа:** мизоҷ ба машғулият сабт мешавад ва шумораи ҷойҳои холӣ дуруст нав карда мешавад.

### 5.5. Баҳисобгирии ҳозиршавӣ

1. Мураббӣ ё корманди ваколатдор рӯйхати иштирокчиёнро мекушояд.
2. Пас аз машқ ҳозир будан ё набудани ҳар як мизоҷро қайд мекунад.
3. Система натиҷаро нигоҳ медорад.
4. Агар шартҳои обуна маҳдудияти шумораи машқҳоро пешбинӣ кунанд, ташриф тибқи қоидаҳои муайяншуда ҳисоб карда мешавад.

**Натиҷа:** таърихи ҳозиршавии мизоҷ нав карда мешавад.

### 5.6. Бақайдгирии пардохт

1. Менеҷер мизоҷ ва обуна ё хизматрасонии дахлдорро интихоб мекунад.
2. Маблағ, сана ва усули пардохтро ворид менамояд.
3. Система дурустии маълумотро месанҷад.
4. Пардохт дар таърихи амалиёт нигоҳ дошта мешавад.

**Натиҷа:** маълумот дар бораи пардохт ба қайд гирифта мешавад.

## 6. Объектҳои иттилоотии соҳаи мавзӯӣ

| Обунаи мизоҷ | Мизоҷ, навъи обуна, санаҳои амал, ҳолат, бақияи ташрифҳо |

## 7. Мушкилоти усули мавҷуда ва асосноккунии автоматикунонӣ

| Сабт бе назорати ғунҷоиш | Аз меъёр зиёд шудани иштирокчиён | Санҷиши ҷойҳои холӣ |
| Набудани таърихи ягонаи ҳозиршавӣ | Душвории таҳлили фаъолияти мизоҷон | Модули баҳисобгирии ҳозиршавӣ |
| Омода кардани дастии ҳисобот | Сарфи вақт ва эҳтимоли хато | Ҳисоботи ҷамъбастӣ |

## 8. Талабот ба системаи коркардшаванда

### 8.1. Талаботи функсионалӣ

Система бояд имкониятҳои зеринро таъмин намояд:

- **FR-01.** Бақайдгирӣ ва воридшавии корбарон.
- **FR-02.** Ҷудо кардани ҳуқуқи дастрасӣ аз рӯйи нақши корбар.
- **FR-03.** Сохтан, дидан ва тағйир додани маълумоти мизоҷон.
- **FR-04.** Пешбурди маълумот дар бораи мураббиён ва ихтисоси онҳо.
- **FR-05.** Идоракунии хизматрасониҳо ва намудҳои обуна.
- **FR-06.** Ба расмият даровардан, тамдид ва назорати обунаҳо.
- **FR-07.** Сохтан ва таҳрир кардани ҷадвали машқҳо.
- **FR-08.** Таъин кардани мураббиён бо санҷиши ба ҳам омадани вақти машқҳо.
- **FR-09.** Сабти мизоҷон бо санҷиши ҷойҳои холӣ.
- **FR-10.** Пешгирӣ аз сабти такрории фаъоли як мизоҷ ба як машғулият.
- **FR-11.** Баҳисобгирии ҳозиршавӣ ба машқҳо.
- **FR-12.** Бақайдгирӣ ва дидани пардохтҳо.
- **FR-13.** Дидани профил, обуна ва таърихи ҳозиршавии шахсӣ аз ҷониби мизоҷ.
- **FR-14.** Таҳияи маълумоти ҷамъбастӣ барои маъмурият.

### 8.2. Талаботи ғайрифунксионалӣ

- **NFR-01. Амният.** Рамзҳо танҳо дар шакли ҳеши криптографӣ нигоҳ дошта мешаванд; ҳуқуқи дастрасӣ дар сервер санҷида мешавад.
- **NFR-02. Якпорчагии маълумот.** Калидҳои ибтидоӣ ва хориҷӣ, маҳдудиятҳо ва транзаксияҳо истифода мешаванд.
- **NFR-03. Қулайӣ.** Интерфейс бояд фаҳмо буда, ҳаракат байни саҳифаҳоро осон намояд.
- **NFR-04. Суръат.** Амалиётҳои маъмулӣ дар шароити сарбории пешбинишуда бе таъхири беасос иҷро шаванд.
- **NFR-05. Мутобиқат.** Барнома бояд дар браузерҳои муосири компютер ва дастгоҳҳои мобилӣ кор кунад.
- **NFR-06. Нигоҳдорӣ ва рушд.** Рамзи барнома бояд сохтори модулӣ ва тақсимоти равшани вазифаҳо дошта бошад.
- **NFR-07. Эътимоднокӣ.** Хатоҳои воридкунии маълумот ва вайроншавии қоидаҳои корӣ бояд бе осеб расонидан ба маълумот коркард шаванд.
- **NFR-08. Махфият.** Корбар танҳо ба маълумоте дастрасӣ дошта бошад, ки барои иҷрои вазифааш зарур аст.

## 9. Қоидаҳо ва маҳдудиятҳои корӣ

1. Ҳисобҳои корбарӣ бояд логин ва/ё суроғаи почтаи электронии такрорнашаванда дошта бошанд.
2. Мизоҷ танҳо ба машғулияте сабт шуда метавонад, ки сабт ба он иҷозат дода шудааст.
3. Шумораи сабтҳои фаъоли машғулияти гурӯҳӣ набояд аз ғунҷоиши муайяншуда зиёд бошад.
4. Як мизоҷ набояд ба як машғулият якчанд сабти фаъоли такрорӣ дошта бошад.
5. Мураббӣ набояд ба ду машғулияти ҳамзамон таъин карда шавад.
6. Сабт бояд ҳолат ва шартҳои обунаро ба назар гирад, агар қоидаҳои клуб инро талаб кунанд.
7. Ҳозиршавӣ бояд ба мизоҷ ва машғулияти мавҷуда тааллуқ дошта бошад.
8. Обунаи муҳлаташ гузашта ё боздошташударо барои амалиёте, ки обунаи фаъол талаб мекунад, истифода бурдан мумкин нест.
9. Маблағи пардохт бояд мусбат бошад.
10. Тағйир додани якчанд сабти ба ҳам алоқаманд бояд дар доираи транзаксия иҷро шавад.
11. Ҳангоми нест кардани маълумоти вобаста қоидаҳои якпорчагии робитаҳо риоя карда шаванд.
12. Ҳолати сабт ва ҳозиршавиро танҳо нақшҳои ваколатдор тағйир дода метавонанд.

Қоидаҳои бекор кардани сабт, баргардонидани маблағ, ях кардани обуна ва кам кардани шумораи ташрифҳо дар марҳилаи таҳияи супориши техникӣ дақиқ карда мешаванд.

## 10. Маълумоти воридотӣ ва содиротии система

### 10.1. Маълумоти воридотӣ

- маълумоти бақайдгирии корбарон;
- маълумоти шахсии мизоҷон ва мураббиён;
- маълумот дар бораи хизматрасониҳо ва намудҳои обуна;
- маълумоти ба расмият даровардан ва тамдиди обунаҳо;
- параметрҳои ҷадвал ва машқҳо;
- дархостҳои сабт ва бекор кардани сабт;
- маълумот дар бораи ҳозиршавӣ;
- маълумот дар бораи пардохтҳо.

### 10.2. Маълумоти содиротӣ

- рӯйхат ва варақаи маълумоти мизоҷон;
- рӯйхати мураббиён ва ҷадвали онҳо;
- феҳристи хизматрасониҳо ва намудҳои обуна;
- маълумот дар бораи обунаҳои фаъол ва муҳлаташон гузашта;
- ҷадвали машқҳо;
- рӯйхати иштирокчиёни машғулиятҳо;
- таърихи ҳозиршавӣ;
- таърихи пардохтҳо;
- нишондиҳандаҳои ҷамъбастии фаъолияти клуб.

## 11. Меъмории пешбинишудаи система

Барои лоиҳа меъмории муштарӣ-серверӣ пешбинӣ мешавад.

**Қисми муштарӣ (Frontend):**
- HTML — сохтори саҳифаҳо;
- CSS — ороиш ва мутобиқшавии интерфейс;
- JavaScript — ҳамкории корбар бо барнома ва фиристодани дархостҳо ба API.

**Қисми серверӣ (Backend):**
- Go — коркарди дархостҳои HTTP ва мантиқи корӣ;
- REST API — мубодилаи маълумот байни frontend ва backend;
- санҷиши маълумоти воридшуда ва ҳуқуқи дастрасӣ;
- идоракунии транзаксияҳо ва робита бо пойгоҳи додаҳо.

**Қабати нигоҳдории маълумот:**
- MySQL — нигоҳдории мутамаркази маълумот;
- SQL — хондан ва тағйир додани маълумот;
- калидҳои хориҷӣ ва маҳдудиятҳо — таъмини якпорчагии маълумот.

Схемаи ҳамкорӣ:

```text
Корбар
   |
   v
Браузери веб (HTML, CSS, JavaScript)
   |
   | HTTP / JSON
   v
Backend (Go, REST API)
   |
   v
Мантиқи корӣ ва санҷиши ҳуқуқи дастрасӣ
   |
   v
Пойгоҳи додаҳои MySQL
```

## 12. Меъёрҳои пешакии муваффақияти лоиҳа

Лоиҳа бомуваффақият ҳисобида мешавад, агар:

1. Корбарон мувофиқи нақши худ ба система ворид шуда тавонанд.
2. Маъмур ва менеҷер дар доираи ваколатҳои худ мизоҷон ва обунаҳоро идора карда тавонанд.
3. Маъмур ҷадвали машқҳоро созад ва мураббиёнро таъин намояд.
4. Мизоҷ машғулиятҳоро дида, ба онҳо сабт шуда тавонад.
5. Система ҳангоми дархостҳои ҳамзамон аз зиёд шудани ғунҷоиши машғулият пешгирӣ кунад.
6. Мураббӣ ё корманди ваколатдор ҳозиршавиро қайд карда тавонад.
7. Маълумоти пардохт ва обунаҳо дуруст нигоҳ дошта шавад.
8. Робитаҳои ҷадвалҳои пойгоҳи додаҳо якпорчагии маълумотро таъмин кунанд.
9. Сенарияҳои асосӣ бе хатоҳои ҷиддӣ санҷида шаванд.
10. Лоиҳа бо ҳуҷҷатҳо ва дастури оғоз ҳамроҳӣ карда шавад.

## 13. Хулоса

Дар натиҷаи таҳлили соҳаи мавзӯӣ мақсад ва вазифаи системаи коркардшаванда, иштирокчиёни асосӣ, равандҳои корӣ, объектҳои иттилоотӣ, мушкилоти баҳисобгирии дастӣ ва талаботи пешакӣ муайян карда шуданд.

Коркарди веб-барномаи ягона имкон медиҳад, ки идоракунии мизоҷон, мураббиён, хизматрасониҳо, обунаҳо, ҷадвали машқҳо, сабтҳо, ҳозиршавӣ ва пардохтҳо дар як система муттаҳид карда шаванд.

Натиҷаҳои таҳлил барои марҳилаи навбатӣ — омӯзиш ва муқоисаи системаҳои мавҷудаи идоракунии фитнес-клубҳо, инчунин таҳияи супориши техникӣ ва моделҳои система — асос мегарданд.
